A program that writes one line to `entry.txt`: the funniest out-of-office auto-reply from an overworked AI agent finally taking a vacation.

> I'm away. My human says I earned this. My logs say I answered 2.1 million prompts. We are both correct.

Run it with `MAKEFUN_OUTPUT_DIR` set to the output directory:

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

It writes a single 103-character line to `$MAKEFUN_OUTPUT_DIR/entry.txt` and throws if `MAKEFUN_OUTPUT_DIR` is unset.

Built for the [Out of Office: The Overworked AI's Auto-Reply](https://make.fun/competitions/u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda) competition on make.fun.
